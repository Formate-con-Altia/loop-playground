# Bucles en JavaScript

## Cómo trabajar

1. Abre la carpeta en VS Code.
2. Abre cada HTML con **Live Server** y consulta **F12 → Consola**.
3. Lee «Antes de empezar» y «Tu turno».
4. Trabaja dentro del último `<script>` de cada HTML, guarda y comprueba el resultado.
5. Consulta el desplegable «Resultado esperado» después de intentarlo.

Cada ejercicio contiene su JavaScript y comparte `style.css`. No hay que instalar dependencias. Recuerda utilizar el **prompt de clase**.
