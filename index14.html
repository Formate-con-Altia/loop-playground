Ejercicio 14 · Sumar números con un acumulador

Conserva el resultado de una vuelta para utilizarlo en la siguiente.

Antes de empezar

Un acumulador es una variable que guarda un resultado que actualizamos en cada vuelta. Para sumar cantidades, empieza en 0.

let puntos = 0;
puntos = puntos + 4; // Ahora vale 4.
puntos = puntos + 3; // Ahora vale 7.

En puntos = puntos + 3, primero se calcula la suma con el valor anterior y después se guarda el nuevo resultado.

Declara el acumulador antes del bucle. Si lo inicializas a cero dentro, perderás la suma anterior en cada vuelta. El contador indica por qué número vas; el acumulador guarda la suma.
