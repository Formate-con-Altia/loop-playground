Ejercicio 3 · Mostrar la iteración

Practica los bucles en la consola del navegador.

Antes de empezar

Un for tiene un inicio, una condición y una actualización. Comprueba la condición antes de cada vuelta. i++ aumenta i en uno.

for (let i = 0; i < 3; i++) {
  console.log("Vuelta " + i);
}

Con inicio 0 y condición i < 3 se ejecutan las vueltas 0, 1 y 2. El límite 3 queda excluido.
