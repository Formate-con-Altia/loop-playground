Ejercicio 7 · Pares e impares

Practica los bucles en la consola del navegador.

Antes de empezar

El operador % devuelve el resto de una división. Si un entero dividido entre 2 tiene resto 0, es par.

console.log(8 % 2); // 0
console.log(7 % 2); // 1

Una comparación como i % 2 == 0 devuelve true o false y puede guardarse en una variable. El cero es par.
