Ejercicio 10 · El día de un Sim

Practica los bucles en la consola del navegador.

Antes de empezar

Puedes incluir condiciones dentro de un bucle. En cada vuelta se evalúan usando el valor actual de i.

for (let i = 1; i <= 3; i++) {
  if (i == 2) {
    console.log("Es el dos");
  } else {
    console.log("Otro número");
  }
}

Un if...else if...else permite elegir una sola opción entre varios casos. El cero no es positivo ni negativo.
