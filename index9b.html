Ejercicio 9b · Extra · Letras de la palabra del día

Practica los bucles en la consola del navegador.

Antes de empezar

texto[i] obtiene un carácter: la primera posición es 0. length indica la longitud e includes() comprueba si una cadena contiene otra.

let texto = "casa";
console.log(texto[0]); // c
console.log(texto.includes("s")); // true

Comprueba primero la posición exacta: una letra bien colocada también aparece dentro de la palabra.

Tu turno

Abre este archivo con Live Server y la consola del navegador (F12 → Consola).

Compara bucle y bueno letra a letra. Primero comprueba si la letra está en la posición correcta; después, si aparece en otra posición; por último, si no está. Supón palabras de cinco letras, en minúsculas y sin letras repetidas en ninguna de las dos.

Lee el código y predice el resultado antes de cambiarlo. Edita el último <script> y guarda para probar. Recuerda utilizar el prompt de clase cuando necesites ayuda.
