Antes de empezar

prompt() devuelve el texto escrito o null al cancelar. El while debe pedir un nuevo intento para que su condición pueda cambiar.

let respuesta = prompt("Escribe tu nombre:");
if (respuesta != null) {
  console.log(respuesta.toLowerCase());
}

Comprueba que el valor no sea null antes de usar toLowerCase(). Con && la segunda condición solo se evalúa si se cumple la primera.
