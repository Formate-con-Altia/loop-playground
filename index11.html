Ejercicio 11 · Dibujar con un bucle

Practica los bucles en la consola del navegador.

Antes de empezar

Las funciones dibujarCirculo() y dibujarHexagono() ya están preparadas. Cada llamada añade una figura al panel.

dibujarCirculo();
dibujarHexagono();

No necesitas modificar las funciones. El número de iteraciones depende del inicio y del límite del bucle.

Tu turno

Abre este archivo con Live Server y la consola del navegador (F12 → Consola).

Sustituye las tres llamadas por un bucle que dibuje numeroFinal - numeroInicial círculos. Con 0 y 10 deben aparecer diez figuras. BONUS: cuando i sea igual a tocaHexagono, dibuja un hexágono en lugar del círculo. Con tocaHexagono = 4 será la quinta figura.

Lee el código y predice el resultado antes de cambiarlo. Edita el último <script> y guarda para probar. Recuerda utilizar el prompt de clase cuando necesites ayuda.

Resultado esperado (pulsa para verlo) 
Base: diez círculos.
BONUS: cuatro círculos, un hexágono amarillo y cinco círculos.
