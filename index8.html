Ejercicio 8 · El límite del while

Practica los bucles en la consola del navegador.

Antes de empezar

while repite su bloque mientras la condición sea verdadera. El contador se prepara antes y se actualiza dentro.

let contador = 0;
while (contador < 3) {
  console.log(contador);
  contador++;
}

Revisa el primer valor, el último y la condición. <= incluye el límite; < lo excluye.
