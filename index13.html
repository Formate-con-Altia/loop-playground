Ejercicio 13 · Bonus · Trimestres con switch

Practica los bucles en la consola del navegador.

Antes de empezar

switch compara un valor con varios casos. Puedes agrupar casos sin instrucciones entre ellos. break termina el caso y default cubre los demás valores.

let opcion = 2;
switch (opcion) {
  case 1:
  case 2:
    console.log("Primera o segunda opción");
    break;
  default:
    console.log("Otra opción");
}

Los casos agrupados comparten las mismas instrucciones. Este bonus se puede hacer después de practicar los bucles.
